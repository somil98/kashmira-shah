# Kashmira Shah - Premium Crockery Sales Website

A modern, responsive website for Kashmira Shah's crockery business, featuring Ektra by Srithai Superware products. This GitHub Pages compatible website showcases premium crockery products with integrated WhatsApp contact functionality.

## Features

### 🏠 Homepage
- Professional portfolio design with hero section
- About section highlighting 10+ years of sales experience
- Featured products showcase
- Contact form with WhatsApp integration
- Modern, light-themed design

### 📋 Product Catalog
- Complete product catalog with 12+ crockery items
- Product filtering by category (Dinnerware, Cookware, Glassware)
- Individual product cards with:
  - Product name and description
  - Original and discounted prices
  - Available quantity
  - Direct WhatsApp contact button

### 📱 WhatsApp Integration
- Floating WhatsApp button on all pages
- Product-specific WhatsApp messages
- Contact form integration with WhatsApp
- Pre-filled messages for easy customer communication

### 🎨 Modern Design
- Clean, minimal light theme
- Responsive design for all devices
- Smooth animations and hover effects
- Professional typography using Inter font
- Font Awesome icons integration

## Technology Stack

- **HTML5** - Semantic markup

- **JavaScript** - Dynamic product loading and interactions

## Setup for GitHub Pages

1. Upload all files to your GitHub repository
2. Enable GitHub Pages in repository settings
3. Select main branch as source
4. Your website will be available at `https://username.github.io/repository-name`

## Customization

### Update Contact Information
- Modify phone numbers in all HTML files and JavaScript files
- Update email address in the contact section
- Change WhatsApp numbers in all WhatsApp links

### Add/Modify Products
- Edit the `products` array in `script.js` for homepage featured products
- Edit the `catalogProducts` array in `catalog.js` for full catalog
- Add product images by replacing emoji placeholders with actual image URLs

### Styling Changes
- Modify color scheme in `styles.css`
- Update fonts by changing Google Fonts imports
- Adjust layout and spacing as needed
